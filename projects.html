I like building software that solves tangible problems — whether that’s an embedded control system, an AI-powered mobile app, or self-hosted infrastructure for privacy and convenience. Here are a few selected projects and demos.

Embedded systems

WS2812B LED Driver

C / Embedded I2C Hardware control

A smart LED control system designed to drive large numbers of WS2812B LEDs using a master/slave architecture over I2C. The goal was to extend effective range while keeping animation control and communication practical.

This project pushed me to think carefully about systems design, device coordination, and reliability at the hardware/software boundary.

Highlights

  • Scalable control: designed for n smart LEDs with master/slave coordination.
  • Communication: used I2C to extend control range and organise device interaction.
  • Hands-on systems work: blended hardware constraints with software logic.
AI mobile app

Intelligent Shopping List Application

OCR LLMs Expense tracking

A mobile app that uses machine vision and language models to scan shopping receipts, extract useful data, and automatically populate shopping lists.

The experience was designed to reduce manual input while also helping users understand spending patterns and manage their budgets more effectively.

Highlights

  • Receipt parsing: turned camera input into structured item data.
  • Budget support: layered expense tracking into the workflow.
  • Applied AI: used LLMs where they improved usability, not just novelty.
Self-hosted infrastructure

Private LAN Server

Django Nginx Media streaming

A personal LAN server designed to replace some public cloud usage with a private, home-based setup for file access, uploads, media streaming, and device connectivity over Wi-Fi.

Features include file and directory downloads with auto-zipping, browser-based media access, thumbnail generation, and bulk file uploads — all aimed at making self-hosting more convenient.

Highlights

  • Convenience: made local infrastructure feel more like a usable product.
  • File workflows: added bulk uploads and archive generation.
  • Privacy-first: reduced dependence on external cloud services.
Machine learning

Dynamic Game Jukebox

Computer vision Games Adaptive audio

A machine learning system that adjusts game music dynamically in response to visual cues, aiming to improve immersion without changing the game itself.

The project explored how lightweight ML-driven context awareness could improve the player experience in a non-invasive way.

Highlights

  • Adaptive behaviour: soundtrack responds to gameplay context.
  • Non-invasive: no need to modify underlying game files.
  • Creative ML: combined technical experimentation with user experience.
